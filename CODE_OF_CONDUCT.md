# Code of conduct

Design Bridge welcomes contributors with different backgrounds and experience levels. Be respectful, discuss ideas
and code constructively, and help others participate. Give useful feedback and accept corrections in good faith.

Harassment, threats, discriminatory language, sexualized comments, deliberate disruption, and publishing another
person's private information are unacceptable. These expectations apply to project issues, pull requests, discussions,
and other spaces representing the project.

To report a problem, open a minimal issue asking the maintainers for a private contact channel. Do not publish private
incident details or personal information. Maintainers should provide a private channel and handle reports discreetly.
This repository does not currently advertise a dedicated moderation email.

Maintainers may edit or remove inappropriate content, limit participation, or exclude people whose behavior violates
these expectations. Responses should be proportionate to the conduct and consistent across participants.
